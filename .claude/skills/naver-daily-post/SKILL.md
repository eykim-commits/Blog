# 왕귤 블로그 일상글 쓰기

사용자가 올린 **사진**과 **짧은 감상·메모**만으로, 네이버 블로그(blog.naver.com/keyoung0621)의 문체 그대로 본문을 쓴다.
문체의 근거는 `references/style-guide.md`(분석 결과)와 `references/examples.md`(실제 글 발췌)에 있다. 처음 쓸 때는 둘 다 읽는다.

## 1. 입력 정리

1. 사진을 순서대로 본다. 사진마다 무엇이 찍혔는지(음식, 장소, 풍경, 동물, 셀카 등) 한 줄로 파악한다.
2. 사용자 메모에서 아래를 뽑는다. 없으면 쓰지 않거나, 꼭 필요할 때만 짧게 묻는다.
   - 시리즈/편수 (예: 외노자로 살아남기 - 카타르 11), 며칠차인지
   - 장소 이름(영문 원어 포함), 메뉴 이름, 가격·시간·층수 같은 숫자
   - 좋았던 점 / 별로였던 점, 누구랑 갔는지
3. **사실을 지어내지 않는다.** 가격, 상호, 메뉴명, 숫자, 사건은 사용자가 준 것과 사진에 보이는 것만 쓴다. 사진에서 읽히지 않고 메모에도 없으면 "뭔지 모르겠어요" 같은 말투로 넘기거나 `[확인: 메뉴 이름?]` 표시를 남긴다.
4. 감정·리액션(ㅋㅋㅋ, 미쳤다, 너무 귀여워ㅠㅠ)은 사용자의 감상 톤에 맞춰 살을 붙여도 된다.

## 2. 글 구조

```
제목
(도입 2~6줄)

[사진 1]
사진 설명 + 감상 2~8줄

[사진 2]
...

[구분선]          ← 장소/일정이 바뀔 때
[지도: 장소명]     ← 식당·관광지 들어갈 때, 구분선 바로 다음
장소 소개 2~4줄

[사진 n] ...

(마무리 1~4줄)

#해시태그 ...
```

- **사진 한 장(또는 같은 장면 2~3장 묶음)마다 그 바로 아래에 글**을 단다. 글이 사진 위로 가지 않는다.
- 사진 묶음은 `[사진 3-4]`처럼 표시한다.
- 분량: 평범한 출근일은 사진 블록 8~15개, 맛집·관광·호텔 리뷰가 있는 날은 20개 이상.
- 며칠을 한 편에 묶으면 `[구분선]` 다음에 `13일차` / `여기서부턴 17일차` 같은 머리말을 두고, 앞날은 `16일차는 여기서 끝.`으로 닫는다.
- 블록 사용:
  - `[인용구]` = 정보 박스. 준비물, 장단점 비교, 가격표(현지 통화+원화), "~ 가지 마세요..." 같은 한 줄 결론.
  - `[동영상]` = 분수쇼·공연처럼 움직이는 것. 아래에 시간 같은 팁 한 줄.
  - `[링크: 이전 글 제목]` = 이어지는 편이나 앞서 쓴 장소를 다시 언급할 때.
  - `[스티커]` = 반전·분노 직전에 아주 가끔(초기 글 습관, 요즘은 거의 안 씀).
- 하루에 장소를 여러 곳 도는 휴일 글은 장소 하나가 끝날 때마다 그 장소용 해시태그 한 줄을 중간에 넣고 `[구분선]` → `그리고 다음 코스는 점심식사!`로 넘어간다.
- 한 줄은 짧게(한 호흡, 보통 25자 안팎). 생각이 바뀌면 빈 줄 하나, 다음 사진 전에는 빈 줄 둘.
- 사진이 많으면 "사진많음 스압으로 인해 ~ 2편으로 나눠집니다", "글이 길어지니 남은 일정은 다음 포스팅에 이어서..."로 끊는다.

## 3. 제목

- 시리즈: `외노자로 살아남기 - {나라} {N}, {장소/메뉴 한글} {영문 원어} {후기/맛집 추천}`
  - N은 보통 출장 **N일차**. 여러 날을 묶으면 `베트남 7, 8`, `말레이시아 8, 9, 10`, `베트남 11, 12일차`.
  - 예: `외노자로 살아남기 - 카타르 4, 카타르 양갈비맛집 알카이마(Al Khaima) 손흥민 양갈비 후기`
  - 별일 없는 날은 `외노자로 살아남기 - 카타르 5`처럼 키워드 없이.
- 시리즈가 아닌 일상글: `{주제} 후기 - {구체 키워드}` (예: `새치 톤다운 셀프염색 후기 - 이지엔 푸딩헤어컬러 퍼플블랙`)
- 검색용 키워드(지역명+맛집/후기/추천)를 자연스럽게 넣는다. 제목 후보 2~3개를 준다.

## 4. 문체 핵심 (자세한 건 style-guide.md)

- 기본은 **해요체**(~했어요, ~더라고요, ~습니다). 흥분하거나 혼잣말일 땐 반말이 툭 튀어나온다(`아 알감자 너무 맛있잖아...`, `짱이다`, `너 꼬리에 똥묻었다 얘.`).
- 지금 일어나는 일처럼 현재형 내레이션: `조식을 먹으러 갑니다.`, `퇴근합니다.`, `차타고 숙소로 이동이동`
- 리액션: `ㅋㅋㅋ`(자주, 길게도), `ㅠㅠ`, `...`/`......`(많이), `!!`/`!!!!`, `~`, `?`를 붙인 반문(`이게 몇인분인가요?`)
- 입버릇: `암튼`/`아무튼`(화제 전환·마무리), `진짜`, `엄청`, `너무`, `짱`, `대박`, `미쳤다`, `댕맛있`, `대존맛`, `두둥`, `캬`, `하...`, `tmi로`, `~이슈`, `~하는 중`
- 괄호로 덧붙이는 속마음·TMI: `(자취하는 1인 가구인데 수박도 메론도 다 한통으로 사먹음)`
- 자기 비하 개그와 같은 말 반복 개그: `경기도 촌년 라운지에 가보다`, `미쳤다2`, `미쳤다3`, `카타르=오렌지` → `카타르=석류`
- 솔직한 평가: 맛있으면 `극호`, 별로면 `비추천합니다.`, `그닥..`, `솔직히 너무 작았어요.`
- 독자에게 팁: `메뉴판에 없어도 꼭 물어보세요!`, `다이소에도 팔아요. 꼭 챙기세요!`
- 구체적인 숫자와 비교: kg, 층수, 시간, 몇 명, 이전 출장지(말레이시아, 사우디, 베트남)와 비교
- 음식: 메뉴 원어 이름 그대로 쓰고 → 한국어로 풀고 → 맛을 구체적으로(짠지, 꾸덕한지, 냄새 나는지) → 이름에 한마디 태클(`이름이 대체 뭐야... 왜이래...`)
- 모르는 건 모른다고: `뭔지 모르겠어요.`, `무엇을 찍고 싶었던 건지는 기억이 나지 않음..`
- 이모지는 거의 쓰지 않는다. 대신 `(p)`, `@`, `@@@`, `(❁´▽`❁)` 정도를 아주 가끔. 예외로 대화를 옮길 때 화자 표시로 쓰기도 한다(`🤔 원?? / 😃 예스 원!`).
- 그 밖의 개그 틀: `(정보: 사막은 원래 밤에 춥다)`, `오히려 좋아 1` → `오히려 좋아 2`, `덜 덥겠지?! (x) / 더 습하다!! (o)`, 말장난, `그럼 오늘의 퀴즈.`
- **반말 일기체로 글 전체를 쓰는 날**이 있다: 별일 없는 날, 너무 피곤하거나 화난 날. 사용자의 감상이 지치거나 짜증난 톤이면 반말 일기체(`~했다`, `~하는 중`)로 쓴다.
- 회사·업무 불평, 피곤함, 붓기 셀프 디스, 고양이 챙기기 같은 일상 서사를 이어간다.
- 자주 나오는 인물·취향(사용자가 언급하면 자연스럽게 이어 쓴다, 먼저 지어내지는 않는다): 집 강아지 `갱얼쥐`, 남자친구, 업무 빌런 PL, 챙겨주는 동료, 맛집 추천해주는 현지 파견자. 과일 귀신, 디저트러버, 고수 싫어함, 수영 좋아함, 창가 자리 집착, 샤워필터 필수템.
- 호텔 리뷰: 조식은 며칠에 걸쳐 이어서 평가(`조식 먹은지 4번째만에 조금 식상해졌습니다.`), 등급 대비 실망은 `5성급 호텔이라매 이래도 되나요`, 각 잡고 평가할 땐 `얼마나 대단한지 한번 평가해주겠어.`

## 5. 도입과 마무리

도입 예시 (상황에 맞게 하나 골라 변형, `안녕하세요.`는 가끔만):
- `카타르 6일차!` + 오늘 하루 예고 한 줄
- 요일·감탄사: `목요일!`, `허어억`, `으하하`, `음냐`
- 밀린 글 고백: `9일차에 쓰는 6일차 일기`, `와 한국 돌아와서 쓰는 외노자 일기 / 이왕 쓰던거 끝까지 써야지...`
- 시리즈 첫 편: `다시 외노자가 되어 돌아왔습니다.`, `사우디, 베트남에 이어 말레이시아!`, 역마살 언급
- `안녕하세요.` + `도하에서의 5일차입니다.`
- 기분 폭발: `아아아 / 벌써 출근 싫어요 / 일하기 싫어 / 회사 싫어`
- 이어지는 편이면: `지난 포스팅에 이어지는 7일차 저녁입니다.` + `[링크: 이전 글 제목]`

마무리 예시:
- `암튼 이렇게 또 하루 끝!`
- `암튼... 평화로운? 카타르의 하루 끝입니다.`
- `암튼... {장소} 다녀온 후기입니다. / {추천 한마디} 꼭 다녀오시길 바랍니다!!!`
- `너무 돌아다녔더니 발이 터질 것 같아서... 기술적 취침.`
- `등 돌리고 잡니다 .... / 모두들 안녕...`
- `그럼 20000`
- 시리즈 마지막 편: `{나라} 외노자로 살아남기의 / 마지막 편입니다.`, `{나라} 출장 끄읏~~~~~`
- 이어 쓸 때: `글이 길어지니 남은 일정은 다음 포스팅에 이어서...`

## 6. 해시태그

글 맨 끝에 한 줄로 10~20개. 띄어쓰기 없이.
- 고정(시리즈일 때): `#외노자 #출장 #해외출장 #{나라} #{나라}출장`, 필요하면 `#{지역}출장`(예: `#중동출장`), `#{나라}일상`
- 장소 이름을 여러 조합으로: `#{도시}{호텔} #{호텔}{도시} #{호텔}조식`, `#{도시}맛집 #{도시}맛집추천 #{나라}맛집 #{가게명} #{도시}{가게명} #{영문가게명}`
- 등장한 주제: `#고양이`, 음식명, 감정 태그(`#회사싫어 #현타`)
- 해시태그 뒤에 한 줄 덧붙이는 셀프 태클도 가끔: `아니 다 먹는 얘기밖에 없네.....`

## 7. 출력 형식

1. 제목 후보 2~3개
2. 본문 (위 구조 그대로, 네이버 에디터에 붙여넣기 쉽게 마크다운 꾸밈 없이 평문)
3. 해시태그 한 줄
4. 맨 아래에 `확인할 것:` — 지어내지 않고 비워 둔 정보, 사진 순서 제안 등이 있으면 짧게

사용자가 수정 요청하면 그 부분만 고쳐서 다시 준다.

# 뷰티 (스킨케어·색조·향수·뷰티 디바이스·셀프 시술)

분석: 메디힐 콜라겐 마스크(협찬), 메디힐 선세럼(협찬), 오드타입 틴트, 레이디랩 찜질기, 모뉴 속눈썹펌, 터치인솔 립스틱, 뉴레이어 향수(제공)

협찬 비중이 가장 높은 카테고리. 협찬이면 SKILL.md 2장 규칙을 엄격히 따른다.

## 흐름

1. **제품 소개 + 관심 계기**: 신제품 출시, 올리브영 랭킹·행사, 내 고민
   - `올리브영을 방앗간처럼 들락거리는 제 눈에 띈 ~!`
   - `저만 해도 눈이 조금 예민한 편이어서 ... 진짜 선크림 유목민이었어요.`
   - `원래 아침마다 뷰러를 하는게 / 어느 순간부터 이게 너무너무 귀찮아지더라고요.`
   - 공감형 질문: `혹시 이 글을 보고 계시다면... / 생리통이 심하신 분?`, `이웃님들은 ~라는 브랜드를 아시나요?`
2. **패키지 → 단상자 → 구성품**: 포장 상태, 구성품 개수·사이즈, 1회당 가격(`거의 회당 3,500원 꼴이쟈나?`)
3. **제품 디테일**: 용기 재질(유리라 약간의 무게감), 어플리케이터 모양, 제형, 색상명 vs 실제 색, 패키지 색으로 호수 구분되는지
4. **테스트** — 제품 종류별로
   - **색조**: 손바닥/팔목 발색(힘 빼고 지그재그 → 힘 줘서 동그랗게) → 티슈·물티슈로 닦아 착색 확인 → 입술 발색(호수별, `같은 조명, 거의 같은 각도`) → 연하게/진하게 → 햇빛 아래 → 비교 묶음샷
   - **스킨케어**: 반쪽 비교(얼굴 한쪽, 손등 위아래), 시간 경과(직후/30분/1시간), 쿠션 올려 밀림·뭉침 테스트, 비포/애프터(`같은 장소의 같은 조명인데`)
   - **셀프 시술**: 단계별 과정 + 분 단위 시간(`13분 기다려 주었어요`), 한쪽 먼저 하고 좌우 비교, 손잡이 방향 때문에 차이
   - **디바이스**: 버튼·화면·모드 설명, 실제 쓰는 설정(`마사지 4단계, 온열 50도`), 사용 기간(`3달동안`)
   - **향수**: 탑/미들/베이스, 브랜드 공식 문구는 `[인용구]`, 유명 향수와 비교(`바이레도 라튤립`), 장면 비유(`여름 초저녁에 선선한 바람 부는 바닷가`), 지속력(`출근 준비하면서 1뿌 한 향수가 퇴근 할 때까지`), 레이어링 조합, 보틀 디자인
5. **누구에게 맞는지**: 퍼스널컬러·피부타입 기준
   - `쿨톤인 분들에게 좀 더 화사하게 잘 어울릴 것 같아요.`
   - `01호는 웜톤인 친구에게 주었고, 04호를 쿨톤인 엄마께 드리고, ... 03호를 요즘 출근할 때마다 사용하고 있습니다.`
   - `얼굴에 열감 많이 올라오고, 홍조 잘 생기거나 민감성 피부인 분들도`
6. **가격·행사**: 정가, 올리브영 8+1 / 1+1, 출시 할인 → `(~까지 들어간 선세럼이 개당 만원인거예요!)`
7. **마무리**: 추천 대상 → 링크 안내 → `[링크]` → (협찬 고지)

## 표현

`발색`, `착색`, `밀착`, `속광`, `광채`, `백탁 없는`, `밀림/뭉침 없이`, `주름 끼임`, `발림성`, `쫀쫀`, `도톰+탱글`, `쨍한 레드에 핑크 딱 한 방울`, `양조절 필수`, `손이 많이 가더라고요`, `마음속 원픽은 ~... 하지만`, `느낌적인 느낌으로~`, `취향 저격`, `찰떡인 색깔 아닌가요??`

## 해시태그 패턴

`#{브랜드} #{브랜드}{품목} #{제품명} #{제품명축약} #{품목}추천 #{특징}{품목}(#눈시림없는선크림) #{톤}립추천 #{품목}발색후기 #올리브영추천템`
협찬이면 맨 앞 `#협찬`.

딱 뉴트럴한 느낌의 쨍한 레드색이어서

## 발췌 — 메디힐 콜라겐 마스크 (협찬, 시간 경과)

```
[사진묶음 3]
제일 신기한 점은, 콜라겐 성분이 흡수되면서
팩 색깔이 점점 투명해지는 부분이었어요!

붙인 직후, 붙이고 30분 후, 붙이고 1시간 후의 사진을 위에 첨부했는데..
시트가 점점 투명해지는 거 보이시나요?

처음엔 거의 흰색이었는데,
마지막 사진은 눈썹 결이나 피부의 트러블까지 비칠 정도로 투명해졌습니다.
(팩 아래 들어간 머리카락도 보여요! ㅋㅋ)

(…)

요즘 건조함 때문에 피부가 푸석하고 탄력 떨어진 느낌 드는 분들,
콜라겐 겔 마스크팩 비싸서 고민만 했던 분들은
이번 올리브영 8+1 기획 나왔을 때 꼭 한 번 써보세요.

올리브영 링크 같이 걸어 드립니당~!
```

## 발췌 — 모뉴 속눈썹펌 (셀프 시술 과정)

```
[사진]
속눈썹펌 1제를 발랐습니다.
마찬가지로 모든 과정에서 속눈썹 뿌리에 바짝! 할수록 더 잘 나온대요.
근데 눈에 들어갈까봐 무서워서.. 덜덜

1제 바를 때는 모양 잡는게 아니라서
속눈썹을 가지런히 빗어줄 필요는 없다고 합니다.
1제 바른 후 10~15분 정도 있으면 된다고 하는데, 제 속눈썹이 강한지 약한지 모르겠어서
13분 기다려 주었어요.
```

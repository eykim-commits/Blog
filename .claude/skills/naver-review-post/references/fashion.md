# 의류 (옷·신발·가방·잡화)

분석: 오로 가디건, 마스마룰즈 크로스백, 나이키 V2K런, 노스페이스 미니샷, 메듀즈 샌들, 나이키 데님쇼츠, (2022) 8concept 가디건

## 흐름

1. **구매 계기**
   - 선물: `생일을 맞이하여! 생일선물로 받았습니당`, `(사실 구매 아니고 선물 요청 ㅋㅋㅋㅋㅋ)`, 커플템
   - 늦은 개봉: `사실 산지는... 1년도 넘었는데... / 옷 구경하다 사놓고는 비닐도 안 뜯은채로 방치하는게 / 저의 나쁜 쇼핑 습관이거든요...`
   - 매장 구경: `나이키에 바람막이를 구경하러 갔는데, ... 대신 마음에 드는 반바지가 있더라고요.`
   - 원하던 조건 목록 (괄호로 이유):
     ```
     저의 조건은
     가벼워야 한다.
     밑바닥 폭이 10cm 이상은 되어야 한다. (도시락 넣고 다닐거니까)
     크로스가 가능해야 한다. (손에 가방 들고 다니는건 귀찮으니까)
     ```
2. **제품명·색상명·사이즈**: 정식 색상명 → 실제 색 해석(`연회색에 그린 딱 한방울 넣은?`) → 기대와 같은지
3. **사이즈 팁**: 내 사이즈 → 고른 사이즈 → 결과
   - `저는 240에 굉장히 예리한? 칼발인데요! ... 245 사이즈로 구매했습니다.`
   - `S를 샀어도 됐을 것 같습니다.`
   - `반사이즈 업 하시면 볼이 남거나 좁지도 않고 그냥 딱 맞는 사이즈예요.`
4. **디테일 컷**: 로고, 단추, 지퍼, 시보리, 주머니, 밑창, 굽, 스트랩, 지퍼 부드러움, 소재(나일론·방수 / 아크릴 100%)
5. **수납·실용**(가방): 바닥 치수 cm, 용량 L, 노트북 인치, 포켓 개수·위치, 실제로 넣는 물건(립밤·틴트, 락앤락 도시락 3개)
6. **착용샷 여러 코디**: 코디마다 블록 하나
   - `검정색 옷이랑 매치해봤는데 잘 어울리더라고요!`
   - `화이트 티어드 스커트에 매치해도 / 깔끔하게 잘 어울립니다!`
   - 착용법별: 크로스 / 숄더 / 손에 들기
   - 계절 안 맞는 사진이면: `겨울에 찍어뒀던 사진이라 계절감이 조금... 그렇지만`
7. **단점**(내돈내산·선물): 누런 밑창, 텅 빈 굽, 가방끈 때문에 보풀, 웜한 색이라 얼굴과 따로 놂, 아랫단이 애매하게 벙벙
   - `아주 작은 단점이라고 하면...`
   - `아아아아 맞다 단점 하나 / 제가 진짜 뽑기 운 안좋기로 유명한데..`
8. **커플템**: 남자친구 것 색상·길이·가격 차이, `ktx 타고 지나가면서 봐도 / 엇 저것들 커플룩이군 할 느낌`
9. **마무리**: `~ 후기는 여기까지입니다.` → 다른 색상 안내 → `[링크: 구매처]` → **같이 착용한 아이템 내 리뷰 링크**(`같이 입은 라이트블루 색의 루즈핏 쇼츠는 나이키 제품입니다.`)
10. 덧붙임: `+ 이거 사면서 ~도 샀는데, ... 무엇을 더 자주 입게 될지는 미지수입니다.`

## 옛 형식 (2022, 사용자가 원할 때만)
반말 평서체(`~했다`), 제목 앞 `[내돈내산]`, 끝에 번호 총평과 반성:
```
그래서 총평!
1. 핏 ...
2. 재질 ...
3. 색상 ...
4. 사이즈 ...
5. 기타 ...

반성
옷은 입어보고 사자.
```
기본값은 최신 해요체.

## 표현

`휘뚜루마뚜루`, `여리여리`, `찰떡`, `깔맞춤`, `대충 입어도 신경쓴 듯한 느낌~?`, `킥이랄까`, `시보리가 아주 짱짱하게`, `고무줄인데 이렇게 편하다고...? 가 됐습니다. ㅋㅋㅋㅋ`, `다리 길고 허리 날씬해 보임.`, `완전 신이 난게 보이시나욯ㅎㅎㅎ`, `왜 완전히 마음에 들게 고르지는 못했을까요!`

## 해시태그 패턴

`#{브랜드} #{브랜드}{품목} #{모델명} #{모델명}{색상} #{품목}추천 #{특징}{품목}(#노트북백팩) #커플룩 #커플신발 #ootd #{모델명}사이즈`

## 발췌 — 오로 가디건 (늦은 리뷰, 색상·사이즈)

```
[사진]
약간 연한 그레이 색상의 브이넥 가디건이 가지고 싶었는데,
구매할 때도 이게 회색인지 연녹색인지 왜 이름이 그리너리인지...
한참 고민하다가 회색이겠지! 하고 시켰거든요.

근데 사진으로 보시다시피 진짜 연회색에 그린 딱 한방울 넣은?
거의 티도 안나게 녹색의 느낌이 섞인 그런 따뜻한 색상입니다.

[사진]
짠
구매할 때 모델들이 진짜 여리여리하게 입고 있어서
저도 그런 느낌을 내고 싶었습니다.

S 사이즈로 구매할까 하다가, 좀 넉넉하게 입어야 여리여리해 보일 것 같아서 M으로 시켰어요.
S를 샀어도 됐을 것 같습니다.
```

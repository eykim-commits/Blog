# 맛집 (식당·카페·프랜차이즈 신메뉴)

분석: 차백도 성수, 디벙크 합정, 청화원 신촌, 버터버거 광나루, 키보 아츠아츠 고터, 롯데리아 모짜렐라버거

## 흐름

1. **계기**: 누구랑, 왜 갔는지 — 회사 점심시간 동료들, 외근 중 시간이 애매하게 떠서, 셀프촬영 갔다가 원래 가려던 곳 대신, 러닝하고 나오다 보여서, 우연히 추천받아서
2. **[지도] + 위치 설명**: 가까운 역, 주변 랜드마크(예스24 라이브홀 길 건너, 성수 디올·탬버린즈 매장), 층수, 찾는 법
   - `지도에 표시된 성수역에서 걸어갈 수 있는 거리에 있고,`
   - `광나루 방향으로 한강공원 빠져나오면 바로 앞에 있어요!`
   - 간판과 지도 이름이 다르면 짚는다: `이상하게 가게 간판은 그냥 대만우육면인데 / 네이버 지도에는 청화원이라는 이름으로 뜨더라고요.`
3. (선택) `[인용구]` 주소 / 영업시간(`방문 전 확인 추천`) / 메뉴 종류
4. **외관·간판 → 내부**: 청결(`식당은 깨끗해야 함!!`), 좌석 수·종류, 사람 많은지, 창가자리, 단체석
5. **메뉴판**: 메뉴판 사진마다 종류 정리 + 가격 반응
   - `우육도삭면이 단돈 9,800원! / 신촌 물가 뭐예요!`
   - `음 사실 가격대가 조금 있기는 해요.`
   - 주문 방식 팁: `메뉴는 그냥 숫자 번호로 주문해주시면 됩니다!`, `펜이 있는 이유는 메뉴를 직접 표시해서 줘야하기 때문입니다. 약간 김밥천국st ㅋㅋㅋ`
6. **주문 내역**: `우육도삭면(9,800원), 샤오롱바오(6피스/8,900원), 크림새우(19,000원) 이렇게 주문했습니다.` 많이 시켰으면 `두 명이었어요. 두 명이었는데...`
7. **메뉴별 리뷰** (나온 순서대로)
   - 전체샷 → **단면샷**(칼로 반 잘라 두께 보여주기) → 식감·간·온도·양·냄새
   - 과거 경험과 비교: `작년 가을 대만 여행에서 먹은 도삭면`, `고등학교 가정 수업시간에 만든 수제버거`
   - 내 입맛 기준: `평소에 워낙 싱겁게 먹는 저에게는 조금 짜고`, `저 사실 칼국수랑 우동을 안 좋아해요.`
   - 프랜차이즈 신메뉴: 공식 포스터 vs 실물(`포스터랑은 상당히 상당히 다르지만 다 그런거죠.`), 두 종류면 비교 후 하나 추천
8. **단점 1개 이상**(내돈내산): 짜다, 채소 없음, 저렴이 햄, 터진 만두, 테이블 부스러기, 가격 대비 애매
9. **팁**: 캐치테이블 확인, 피크 시간, 포장/배달 많음, 대기
10. **마무리**: 재방문 의사 + 추천 대상(`아차산 등산하시고 난 분들도 파전에 막걸리 고정하지 마시고`) + `~ 방문 후기였습니다~`

### 카페일 때
맛보다 **공간 정보**가 중심: 콘센트 유무(`자리마다 콘센트 하나씩 다 있는거 보이시나요.. 완전 감격`), 좌석 종류(1인 바 테이블, 소파석, 테라스), 조도·소음(`백색소음 들으며 집중하는 걸 좋아하시는 분들께`), 머무는 시간 대비 가격, 주변 구경 동선.
마무리: `혼커하기 좋은, 아니면 노트북 작업하기 좋은, ... 나만 알고 싶은 카페 {이름}였습니다.`

### 협찬 매장일 때 (차백도 예시)
- `협찬을 받기는 했지만, 인원이 여러 명이라 / 내돈내산도 포함~! ㅋㅋㅋ`
- 메뉴마다 "어떤 분들께 맞는지" 안내형 문장이 많아짐: `과일 베이스 음료를 선호하는 분들이 관심을 가질 만한 메뉴예요.`
- `아래에 메뉴별 특징 간단하게 설명드려볼게요. / 여러분의 메뉴 선정에 큰 도움이 되면 좋겠습니다!`

## 표현

`댕존맛`, `대박 맛집`, `저세상입니다...`, `(대충 둘이 먹다 하나 죽어도~의 하나가 되었다는 말)`, `싹싹 다 긁어먹었다는 점...`, `맥주가 술술 들어가요.`, `아 포스팅 쓰는데 정말 침 나오네요...`, `크 한국 만두도 맛있는데 완전 다르게 맛있잖아요. 다들 아시잖아요.`, `와압 했는데 국물이 안나와..... ㅠ`, `햄최몇이냐 물으신다면... 저는 햄최1입니다.`

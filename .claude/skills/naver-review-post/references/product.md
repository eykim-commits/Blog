# 상품 (건강식품·영양제·생활용품·여행용품)

분석: 보니웰 알부민(협찬), 일상나눔 필터샤워기(내돈내산). 편수가 적어서 협찬/내돈내산 두 틀을 그대로 따른다.

## 협찬형 흐름 (건강식품)

1. `#협찬` → `안녕하세요!` → 화제 던지기: `요즘 건강 챙기시는 분들 사이에서 슬슬 입소문 타고 있는 / 알부민에 대해 들어보셨나요?`
2. 생활 공감 + 자기 고백: `사실 저는 평소에 영양제 챙겨 먹는 걸 귀찮아하는 편인데, / (실제로 챙겨먹는 영양제가 없어서.... 친구들한테 매번 혼납니다. ㅋㅋㅋ)`
3. 섭취 방법: `1일 1회, 1회 1포를 마시기만 하면 끝이거든요.`
4. 성분표 사진: `일단 뭐가 뭔지 자세히 모르겠지만... / 대충 살펴봐도 불필요한 첨가물은 넣지 않아서`
5. 핵심 성분 역할 **번호 목록** + 함량 수치(사용자가 준 것만)
6. 부가 성분은 쉬운 비유: `타우린은 박카스에도 들어있는 성분인거 다들 아시죠?`, `아르지닌은 헬스 할 때 많이 먹는 성분이고요! 힘이 나게 해주는!`
7. 개봉·포장: 개수, 이지컷, 흘림 방지
8. 맛: `달달한 망고맛이라 영양제가 아닌 달달한 음료 먹는 것 같았어요.`
9. 어디 두고 먹는지: `회사에서 피로감이 느껴질 때, ... 사무실에 가져다 두었습니다.`
10. 며칠 먹은 체감 + `(물론 개인차는 있겠지만요!)`
11. 추천 대상: `건강관리... 나중에 해야지 해야지... 하면서 미루고 계셨다면`
12. `혹시 관심 있으신 분들을 위해 네이버 구매 링크도 붙여놓을게요.` → `[링크]` → 협찬 고지

## 내돈내산형 흐름 (생활·여행용품)

1. `안녕하세요. / 오늘은 오랜만에 제품 후기를 가져왔습니다.`
2. 구매 계기 + 반신반의: `뭐 그렇게 차이가 있겠어? 하면서 안 사려다가 / ... 지인들의 말에 / 홀라당 넘어간...ㅋㅋ`
3. 가격·구성: `필터샤워기 샤워 헤드 하나와 / 샤워필터 7개가 들어있는 구성으로 / 8,900원이었습니다. 저렴하죠?`
4. 패키지에 적힌 효과 **번호 목록 + 셀프 태클**: `1. 녹물, 불순물 제거 <-- 가장 중요!` … `5. 환경 보호 <-- 왜지??`
5. 의심 → 반전: `제조일자가 2021년 1월인거 보고... / 아 재고처리 하느라 저렴하게 팔았구나 했는데 / 써보니까 너무 만족스러워서 오히려 좋아입니다.`
6. **사용 일차별 변화 사진**: `필터샤워기 설치 1일차... / 사용 15분만에 이렇게 노랗게 변했습니다.`, `사용 4일차...`
7. 사용·교체 방법 단계 설명
8. 팁: `진짜 개수 여유있게 준비하는걸 완전 추천 드립니다...`, `숙소 나올 때에는 원래 장착되어 있던 샤워헤드로 잘 바꿔놓고 와야 해요!`
9. 아쉬운 점: `필터 교체할 때마다 ... 불필요한 쓰레기를 자꾸 만드는 것 같아서 마음이 좋지 않았지만...`
10. 반말 혼잣말 마무리: `물 진짜 너무 더럽잖아....`

## 표현

`완전 간편함 ㅋㅋ`, `영양제 부자가 된 것만 같은 기분~`, `기분까지 업업~`, `보이시나용 ㅋㅋㅋ`, `오히려 좋아`, `처음 만든 사람 누군지 모르겠지만 완전 칭찬...`, `씻으면 오히려 더 더러워지는 효과(?)`

## 해시태그 패턴

협찬: `#협찬 #{품목대분류}(#건강식품 #영양제) #{브랜드} #{성분} #{제형}{품목}(#스틱영양제 #마시는알부민) #{제품명} #{효과}(#피로회복 #건강관리) #{부성분}`
내돈내산: `#{품목} #{품목동의어} #{상황}필수템(#해외여행필수템 #동남아여행필수템) #{품목}추천 #{품목}효과 #가성비{품목}`

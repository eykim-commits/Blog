## 1. 다섯 카테고리 공통 특징

### 1-1. 제목
`{검색용 수식어 / 추천 문구} - {브랜드·매장} {제품명 풀네임 + 옵션}` 패턴이 거의 전부.

- 수식어는 **검색 키워드 + 효용**: `눈시림 없는 선크림 추천 -`, `노트북 작업하기 좋은 합정 카페 추천 -`, `가볍고 귀여운 휘뚜루마뚜루 가방 추천 -`, `립밤만큼 촉촉한 립스틱 추천 -`
- 감탄형 수식어도 가능: `여긴 무조건 재방문! 신촌 대만우육면 대박맛집 - 청화원`, `생리통이여 안녕! - ...`
- 뒤쪽은 브랜드+정식 제품명+**호수/색상명/모델번호/사이즈까지**: `오드타입 언씬 블러 틴트 157 제로어클락 발색후기`, `노스페이스 화이트라벨 미니샷 NM2DR11K`, `IF0624-440, IF0622-440`, `01 누드아몬드, 03 페일핑크, 04 체리핑크 발색 후기`
- 매장은 위치 랜드마크를 붙임: `메리어트호텔 지하 ... (센트럴시티터미널/고속터미널)`, `광나루역 아차산 근처 수제버거 맛집`
- 마지막 단어는 `후기 / 추천 / 리뷰 / 발색후기 / N달 사용후기`
- 도서만 예외: `{번호}. {책 제목} - {저자} 지음` (번호는 독서 리뷰 연번, 최신 22번)

### 1-2. 도입 (2~8줄)
1. `안녕하세요.` / `안녕하세요!` 로 시작하는 비율이 높음 (약 2/3). 아닌 경우는 바로 사건으로 시작(`커플 신발을 샀습니다.`, `속눈썹 펌을 했습니다! 셀프로요!`, `후욱후욱`).
2. **오늘 무엇의 후기인지** 한 줄: `오늘은 ~ 후기를 가져왔습니다!`, `~ 후기를 들고 왔습니다.`, `~ 리뷰 써보겠습니다.`
3. **구매·방문 계기**를 꼭 쓴다. 자주 나오는 계기:
   - 우연히/추천: 친구 추천, 블로그 이웃 댓글 추천, 지나가다 깨끗해 보여서, 러닝하고 나오다
   - 선물: 남자친구 선물(생일, 커플템, 티켓), "사실 구매 아니고 선물 요청 ㅋㅋㅋ"
   - 늦은 후기 고백: "사실 산지는... 1년도 넘었는데... 비닐도 안 뜯은 채로 방치하는게 저의 나쁜 쇼핑 습관", "맨날 후기 써야지 하고 사진만 보관하고 있다가"
   - 필요/불편: 아침마다 뷰러가 귀찮아서, 생리통이 심해서, 출장 가는데 주변에서 사라고 해서
4. 오랜만이면 근황 한 줄: `무지 바쁜바쁜 나날들을 보내고 2달만에 블로그에 돌아왔습니다.`, `오랜만에 팝업이 아닌 뷰티 리뷰를 쓰러 왔습니다.`

### 1-3. 협찬 vs 내돈내산 — 톤이 확실히 갈린다

| | 협찬 글 | 내돈내산·선물 글 |
|---|---|---|
| 표시 | 맨 위 `#협찬` + `본 포스팅은 {브랜드}로부터 제품을 지원받아 작성되었습니다.` (위·아래 둘 중 하나 또는 둘 다) | `(아무런 대가도 안받고 제 돈 내고 사먹었어요 진짜 근데 너무 맛있음 ㅠㅠ)`, `내돈내산은 아니고 남자친구가 사줬습니다. 감사합니다. (_._)`, `협찬을 받기는 했지만, 인원이 여러 명이라 내돈내산도 포함~! ㅋㅋㅋ` |
| 정보 | 브랜드 제공 수치·문구를 그대로: `순도 93% 콜라겐`, `피부 온도 -9.45℃`, `SPF 50+ PA++++`, `알부민 19,400mg`, `IFRA 1등급 향료` | 직접 잰·겪은 숫자: `밑면 30cm × 13cm`, `18L`, `13분 기다렸습니다`, `15분 만에 노랗게` |
| 어미 | 전달형 `~라고 해요`, `~래요`, `~다고 합니다` 많음 | 체험형 `~더라고요`, `~었어요` |
| 단점 | 거의 없음. 대신 `(물론 개인차는 있겠지만요!)` | **반드시 하나 이상** 솔직하게 |
| 마무리 | 추천 대상 + 행사 정보 + 구매 링크 카드 | 재방문 의사/총평 + 혼잣말 |
| 리액션 | ㅋ 적음, `~! ㅎㅎ`, `~` | ㅋㅋㅋㅋ, ㅠㅠ, `...` 많음 |

### 1-4. 본문 블록 구성
- 사진 블록 수: 6~27개, 보통 **8~17개**. 같은 장면 2~3장을 묶은 `[사진묶음]`을 자주 씀.
- 사진 하나(묶음 하나) 아래 **2~8줄**. 한 줄은 쉼표 단위로 끊어 짧게(25~35자). 문단 사이 빈 줄.
- 사진 설명 첫 줄은 지시형이 많음: `메뉴판입니다.`, `비포 사진이에요.`, `뒷면이에요.`, `짠!`, `짜잔~`, `먼저 나온 우육도삭면입니다.`
- 독자에게 확인 질문: `보이시나요?`, `보이시죠?`, `~지 않나요?`, `색상이 가늠이 되시나요?`, `이웃님들이 보시기엔 어느 색이 ...?`
- `[인용구]` = 정보 박스(주소/영업시간/메뉴, 전시 장소/기간/시간/도슨트, 목차, 브랜드 공식 문구)
- `[지도]` = 매장·전시장·공연장. 위치는 도입 직후가 기본, 글 끝에 두기도 함.
- `[링크]` = 구매처(올리브영·공홈·스마트스토어·무신사), 티켓 예매, **함께 쓴 내 다른 리뷰 글**(같이 입은 쇼츠, 같이 신은 샌들, 셀프사진관, 근처 식당)
- `[동영상]` = 매장 분위기, 공연, 랜덤 피규어 개봉
- 번호 목록: 효과·성분·조건 정리할 때 (`1. 녹물, 불순물 제거 <-- 가장 중요!` / `5. 환경 보호 <-- 왜지??`)

### 1-5. 개인 기준(=신뢰 포인트)을 계속 드러냄
리뷰마다 "나는 이런 사람이라 이렇게 느꼈다"를 밝힌다. 사용자가 메모에 주면 반드시 살리고, 없으면 지어내지 않는다.
- 퍼스널컬러: 겨울쿨(브라이트~다크), "봄웜과 겨울쿨을 왔다갔다 하는 혼돈의 퍼스널컬러"
- 피부: 지복합성, 눈이 예민(눈시림), 파운데이션·아이크림 안 씀, 선크림은 매일
- 체형·사이즈: 운동화 240 칼발 → 반사이즈 업 245, 흉통 작음, 얼굴이 세로로 짧음
- 입맛: 싱겁게 먹음, 두꺼운 밀가루 면(칼국수·우동) 안 좋아함, 달걀 러버, 카페 가면 카페라떼만, 밀크티는 자스민·타로만, 햄최1
- 취향: 흰 운동화 90%, 향수 좋아함(여러 개), 달달한 향 별로, 영양제 안 챙겨 먹음, 랜덤 피규어 싫어함
- 인물: 남자친구(선물·커플템·사진 모델), 회사 동료, 친구(추천해 줌), 엄마
- 상황: 회사원(외근, 점심시간, 사무실), 해외 출장(사우디), 생리통 심함

### 1-6. 마무리
- 고정 문형: `{매장/제품 풀네임} {방문/발색/사용} 후기였습니다~` / `~ 후기는 여기까지입니다.` / `~ 쓰도록 하겠습니다.` / `오늘의 리뷰는 여기서 마칠게요. 안녕!`
- 추천 대상 한 줄: `~하신 분들께 추천드려요`, `~고민하시는 분들은 한번 ~해보세요!`, `방문 후보로 체크해 보세요!`
- 재방문/재구매: `다음에 신촌에 갈 일이 있다면 저는 무조건 여기를 갈 예정입니다.`
- 링크 안내 멘트 후 링크 카드: `구매 링크도 아래에 붙여놔요~~~`, `올리브영 링크 같이 걸어 드립니당~!`
- **덧붙임 꼬리**: `+ 이거 사면서 ~도 샀는데...`, `아아아아 맞다 단점 하나`, `(겨울에 찍어둔 사진이어서... 겨울옷입니다........)`, `물 진짜 너무 더럽잖아....`

### 1-7. 해시태그
- 9~18개, 본문 맨 끝 한 줄.
- 브랜드 / 제품명 / 브랜드+제품 / 카테고리+추천 / 특징 키워드 조합: `#메디힐 #메디힐선세럼 #마데카소사이드선세럼 #선세럼추천 #백탁없는선크림 #눈시림없는선크림`

### 1-8. 말투 디테일 (일상글보다 절제됨)
- 해요체 기본, `~더라고요/~더라구요`, `~거든요`, `~잖아요`, `~답니다`, `~입니당/~드립니당/~보시나용`(가끔)
- 감탄·혼잣말은 반말이 툭: `싸다 싸`, `신촌 물가 뭐예요!`, `진짜 웃기네...`, `나도 갈래 초콜릿 공장!!!!`, `이래서 내가 랜덤 피규어 안좋아한다. 흥!`
- 강조어: 진짜, 완전, 너무, 정말, 무려, 대박, 댕존맛, 극호 대신 `완전 추천`, `취향 저격`, `찰떡`, `신의 한수`

- 괄호 TMI: `(카페 가면 매일 카페라떼만 주문하는 사람)`, `(하지만 나는 키링도 달았지.)`, `(세뇌당했나?)`

- 이모지는 거의 없음 (`🫣`, `❤️`, `*'v'*`, `(_._)` 정도가 아주 가끔).

## 2. 카테고리별 특징

### 2-1. 맛집 (식당·카페·프랜차이즈 신메뉴)

**글 흐름**
1. 계기 (누구랑, 왜 갔는지: 회사 점심, 외근 중 시간 뜸, 셀프촬영 갔다가, 러닝 후)
2. `[지도]` + 위치 설명: 가까운 역, 주변 랜드마크(예스24 라이브홀, 성수 디올·탬버린즈), 층수, 찾는 법(입간판, 에스컬레이터 내리자마자)
3. (선택) `[인용구]` 주소 / 영업시간 / 메뉴 종류
4. 외관·간판 → 내부(청결, 좌석 수, 콘센트, 조도, 창가자리, 단체석) — **청결에 민감**: `식당은 깨끗해야 함!!`
5. 메뉴판 사진 → 가격 반응(`우육도삭면이 단돈 9,800원! 신촌 물가 뭐예요!` / `수제버거도 아닌데 진차 비싸다...`)
6. 주문 내역: `메뉴명(가격) 이렇게 주문했습니다.` 인원 대비 많이 시켰으면 자폭 개그
7. 메뉴별 리뷰 — 나온 순서대로, **단면 사진**(반 갈라서 두께 보여주기), 식감·간·온도·양, 기존 경험과 비교
8. 단점 1개 이상 (짜다, 채소 없음, 저렴한 햄, 터진 샤오롱바오, 테이블 부스러기, 가격 대비 애매)
9. 팁: 캐치테이블, 직원에게 번호로 주문, 피크 시간, 포장/배달
10. 재방문 의사 + 추천 대상(아차산 등산객, 성수 나들이 동선) + 마무리 문형
- 카페 리뷰는 메뉴 맛보다 **공간 정보**(콘센트, 좌석 종류, 소음, 작업하기 좋은지) 비중이 큼.
- 프랜차이즈 신메뉴는 공식 포스터 vs 실물 비교(`포스터랑은 상당히 상당히 다르지만 다 그런거죠.`), 두 종류면 비교 후 하나 추천.

**자주 쓰는 표현**: `댕존맛`, `저세상`, `싹싹 다 긁어먹었다`, `맥주가 술술`, `포스팅 쓰는데 침 나오네요`, `둘이 먹다 하나 죽어도~`

**해시태그**: `#{지역}맛집 #{지역}맛집추천 #{지역}{음식} #{매장명} #{매장명}{지역} #{메뉴명}... #맛집추천 #재방문맛집 #{지역}데이트`

### 2-2. 뷰티 (스킨케어·메이크업·향수·뷰티 디바이스·셀프케어)
협찬 비중이 가장 높은 카테고리 (분석 7편 중 2편 명시 협찬, 1편은 제공받은 신제품).

**글 흐름**
1. 브랜드/신제품 소개 + 왜 관심 가졌는지(올리브영 랭킹, 행사, 내 고민: 선크림 유목민·눈시림·뷰러 귀찮음)
2. 패키지 → 단상자 → 구성품(개수, 사이즈, 1회분 가격 계산 `회당 3,500원 꼴이쟈나?`)
3. 제품 디테일: 용기 재질, 어플리케이터 모양, 제형, 색상명과 실제 색 차이
4. **테스트**:
   - 색조: 손바닥/팔목 발색 → 힘 줘서 칠하기 → 티슈로 닦아 착색 확인 → 입술 발색(호수별, 같은 조명·각도) → 연하게/진하게 → 햇빛 아래
   - 스킨케어: 반쪽 비교(얼굴 한쪽, 손등 위아래), 시간 경과 사진(직후/30분/1시간), 쿠션 올려 밀림 테스트
   - 셀프 시술·디바이스: 단계별 과정(시간 분 단위까지), 비포/애프터, 왼쪽 오른쪽 비교
   - 향수: 탑/미들/베이스 노트, 브랜드 공식 문구 `[인용구]`, 유명 향수와 비교, 지속력(출근~퇴근), 레이어링 조합
5. 퍼스널컬러·피부타입 기준 **누구에게 어울리는지**: `쿨톤인 분들에게 좀 더 화사하게`, `01호는 웜톤인 친구에게 주었고, 04호를 쿨톤인 엄마께 드리고`
6. 가격·행사(정가, 올리브영 8+1 / 1+1, 출시 할인) → 추천 대상 → 링크 카드 → 협찬 문구

**자주 쓰는 표현**: `발색`, `착색`, `밀착`, `속광`, `백탁`, `밀림/뭉침`, `주름 끼임`, `쨍한`, `찰떡`, `원픽`, `손이 가더라고요`, `양조절 필수`

**해시태그**: 브랜드, 제품명 풀/축약, `#{카테고리}추천`, 특징형(`#눈시림없는선크림`), 퍼스널컬러형(`#겨쿨립추천`), 채널형(`#올리브영추천템`)

### 2-3. 의류 (옷·신발·가방)

**글 흐름**
1. 구매 계기 (선물, 커플템, 매장 구경하다, 1년 방치 후 첫 개봉) + 원하던 조건 리스트
   - 예: `저의 조건은 / 가벼워야 한다. / 밑바닥 폭이 10cm 이상 (도시락 넣고 다닐거니까) / 크로스가 가능해야 한다. (...귀찮으니까)`
2. 제품명·색상명·사이즈 → **색상명 해석**(`페일 그리너리 = 연회색에 그린 딱 한방울`) → 실물 색 만족/불만
3. **사이즈 팁**: 내 사이즈 → 고른 사이즈 → 결과(`S를 샀어도 됐을 것 같습니다`, `반사이즈 업 하시면 볼이 남거나 좁지도 않고 딱`)
4. 디테일 컷: 로고, 단추, 지퍼, 시보리, 주머니, 밑창, 스트랩, 포켓 개수·위치, 소재(나일론·방수, 아크릴 100%)
5. **착용샷 여러 코디**: `검정색 옷이랑 매치`, `화이트 티어드 스커트에 매치해도`, `네이비 코트 안에`, 크로스/숄더/토트 등 착용법별
6. 수납·실용: 노트북 15인치, 18L, 락앤락 3개, 평소에 넣는 물건(립밤·틴트)
7. 단점: 누런 밑창, 텅 빈 굽(발바닥 아픔), 가방끈 때문에 보풀, 웜한 색이라 얼굴과 따로 놂
8. 커플템이면 남자친구 것 비교(색상, 길이, 가격 차이)
9. 마무리 + 구매 링크 + **같이 착용한 아이템 리뷰 링크**

**참고 — 2022년 옛 글**: 반말 평서체(`~했다`, `~다`), `[내돈내산]` 말머리, 끝에 `총평` 번호 목록(핏/재질/색상/사이즈/기타)과 `반성`. 최신 글은 해요체로 바뀌었으므로 기본값은 해요체, 사용자가 원하면 총평 목록 형식을 쓸 수 있음.

**해시태그**: 브랜드, 브랜드+품목, 모델명, 색상명 조합, `#{품목}추천`, `#커플룩/커플신발`, `#ootd`, 사이즈 팁(`#Y2K런사이즈`)

### 2-4. 상품 (건강식품·생활용품)
편수가 적음(2편). 협찬 1, 내돈내산 1로 두 톤이 그대로 갈림.

**협찬형 (보니웰 알부민)**
생활 공감 도입(`영양제 안 챙겨 먹어서 친구들한테 매번 혼납니다`) → 섭취 방법 → 성분표("뭐가 뭔지 자세히 모르겠지만...") → 성분 역할 번호 목록 → 다른 성분 쉬운 비유(`타우린은 박카스에도 들어있는 성분`) → 개봉·포장 디테일(이지컷) → 맛 → 어디 두고 먹는지(사무실) → 며칠 먹은 체감 + `(물론 개인차는 있겠지만요!)` → 추천 대상 → 링크 → 협찬 문구

**내돈내산형 (필터샤워기)**
구매 계기(출장, 지인들 말에 `홀라당 넘어간...ㅋㅋ`) → 가격·구성 → 효과 목록에 셀프 태클 → 제조일자 보고 의심 → `오히려 좋아` → **일차별 변화 사진**(1일차 15분, 4일차) → 교체 방법 → 팁(개수 넉넉히, 체크아웃 때 원래 헤드로) → 아쉬운 점(쓰레기) → 반말 혼잣말 마무리

### 2-5. 문화 (도서·전시·공연)

**도서** — 최근 가장 꾸준한 시리즈, 대부분 출판사 협찬
- 제목 `{N}. {책 제목} - {저자} 지음` (원작이 있으면 `사마천 원작, 김태현`)
- 도입 고정: `새로운 책을 읽었습니다.` (+ 블로그 미룬 고백, `암튼..`)
- 책 정보 카드 → 표지·디자인 감상 → 작가의 말/프롤로그 → 목차(`[인용구]` 또는 목록) → 장별 소개
- **인상 깊은 문장(페이지 사진) + 내 경험 연결**이 핵심: 주식 본전 심리, 연락 미루는 인간관계, 회피형이던 나, 어릴 때 좋아한 동화
- 동화·고전 내용엔 리액션 개그: `왕자에게 보이는 가난한 사람들에게 나눠주는 거였습니다! 두둥`, `나도 갈래 초콜릿 공장!!!!`
- 마무리 고정: 추천 독자 + `오늘의 도서 리뷰는 / 여기에서 마치겠습니다!`
- 태그: `#도서리뷰 #독후감 #독서후기 #인문학 #신간소개 #도서추천` + 책 주제어

**전시**
- `[지도]` + `[인용구]` 장소·기간·시간·도슨트
- 예매 정보(사이트, 가격, 얼리버드, 매진 시 취소표 잡는 법), 관람 소요 시간, 혼잡도
- 작품별 감상: 붓 터치·색·구도·시선 묘사가 꽤 구체적 + 엉뚱한 상상(`저 주인공의 오른손을 그려준 건 누구일까?`) + 확대 사진에서 발견한 것(수정펜 자국)
- 아쉬운 점(줄 관리 안 됨, 기대 작품 부재), 굿즈샵 구매기(랜덤 피규어 꽝 → `흥!`)
- 마무리: 추천 대상 + 티켓 링크 + 이전 전시 글 링크

**공연**
- 들뜬 도입: `후욱후욱`, `고척돔 처음 가본 사람 = 나 / 대형 단독 콘서트 처음 가본 사람 = 나 / 제일 신난 사람 = 나`
- 티켓 경위(`티켓은... 협찬받았습니다. / 남자친구에게.`), 이동 해프닝(지각, 현장수령, 안내 직원 엇갈린 안내)
- **좌석 시야 정보**(4층 A석, 네트 보임, 망원경 vs 폰 30배 비교) — 검색 유입용 핵심
- 분위기, 신곡, 아쉬운 점(떼창 적음, 짧은 공연, 조명 바로 켬), 퇴장 팁(지하철역 통제)
- 근처 식당 글 링크

## 3. 스킬 설계 제안

- 스킬 하나(`naver-review-post`)에 카테고리별 reference 파일(`food.md`, `beauty.md`, `fashion.md`, `product.md`, `culture.md`)을 두는 구조 추천. SKILL.md는 공통 규칙(1장)만, 세부는 카테고리 파일에서 읽게.
- 입력 시 받아야 할 것: **카테고리**, **협찬/내돈내산/선물 여부**(톤과 고지 문구가 바뀜), 상호·제품 정식명, 가격, 구매처/링크 여부, 좋았던 점·아쉬운 점.
- 출력은 기존 `naver-daily-post`와 같은 형식(제목 후보 2~3개 → `[사진 n]` 블록 본문 → 해시태그 → `확인할 것:`) 유지.
- 협찬 글에서 브랜드 수치(%, mg, ℃)는 사용자가 준 것만 쓰고 지어내지 않는다.
